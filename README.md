# Moxyart Marketing website

Source repository for the Moxyart Marketing website.

## Status

The visual design is in [Figma](https://www.figma.com/design/CrGSFrkFSC8tIfeKaAulna/Marketing-website?node-id=194-8). A first draft of the one-page site is built as plain HTML, CSS and JavaScript (`index.html`, `styles.css`, `script.js`). No build step is needed. The project tiles still need images before launch.

## Deployment plan

Once the website is built, connect this GitHub repository to Netlify. Netlify will deploy updates from the `main` branch.
